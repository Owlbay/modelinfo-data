# ModelInfo Data

[modelinfo.dev](https://modelinfo.dev) 的模型数据：模型规格、价格与供应商，每个数值都来自模型厂商的官方页面。

- `models/`：每个模型一个 JSON 文件
- `vendors/`：模型厂商
- `providers/`：API 供应商

合并到 `main` 的改动会自动同步到 modelinfo.dev 与 `https://modelinfo.dev/v1/models`。

欢迎提 PR 补充新模型、更新价格或修正错误，规则见 [CONTRIBUTING.md](CONTRIBUTING.md)。
